# harshini-kanagarla-multi-state-config

GitOps configuration repository for `multistate-api` (W6D2). Argo CD
reconciles this repo's `overlays/{dev,staging,prod}/` into the
`multistate-dev`/`multistate-staging`/`multistate-prod` namespaces.

See the `w6d2-implementation` branch / PR for the current deliverable.
